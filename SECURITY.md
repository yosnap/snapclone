# Seguridad

## Versiones con soporte

Solo la última release publicada recibe correcciones de seguridad.

## Informar de una vulnerabilidad

No abras una issue pública. Envía el informe de forma privada desde la pestaña [Security → Report a vulnerability](https://github.com/yosnap/snapclone/security/advisories/new) del repositorio.

Incluye la versión afectada, los pasos para reproducirlo y el impacto que crees que tiene. Recibirás una primera respuesta en un plazo de 7 días. Cuando haya una corrección publicada, se te reconocerá el hallazgo si así lo quieres.

## Qué datos maneja Snapclone

Snapclone funciona sin conexión. No envía capturas, texto reconocido ni estadísticas a ningún servidor. Las capturas, el historial y los ajustes se guardan solo en tu Mac, en `~/Library/Application Support/com.paulo.snapclone`.
